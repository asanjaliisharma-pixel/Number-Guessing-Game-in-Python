Number Guessing Game in Python

A simple and interactive Number Guessing Game built using Python. In this game, the computer randomly selects a number, and the player has to guess the correct number.

The game provides hints to help players guess whether their number is too high or too low until they find the correct answer.

Features
Random number generation
User-friendly interface
Hints for higher or lower guesses
Counts the number of attempts
Beginner-friendly Python project

Technologies Used
Python
Random Module
Conditional Statements
Loops
User Input

How to Run
Clone this repository.
Open the project folder.
Run the Python file: python number_guessing_game.py
Start guessing the number!

Purpose

This project is created to practice Python basics and improve logical thinking through a fun mini-game.
